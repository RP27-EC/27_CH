# C 板 EKF 切换与验证

上层 C 板使用 BMI088 解算姿态。默认启用 EKF，保持原有板间通信接口与符号处理。

## 修改

- Mahony 和 EKF 安装角均为 Z=180°、Y=180°、X=0°。修复 Mahony 注释未闭合导致 Y 配置被吞掉的问题；修复后与此前实际生效的安装方向不同，必须核对上板轴向。
- 初始化加速度先转换到安装坐标系，再按 ZYX、yaw=0 计算 `[w,x,y,z]` 四元数。
- 校准完成后，两种算法均应用三轴静态补偿。EKF 的 X/Y 状态从总零偏转换为残余零偏，输入补偿与状态转换在同一帧生效；同步 `xhat_data`、`xhatminus_data`、`FilteredValue` 和 `GyroBias`，避免后续更新覆盖缓存或再次扣除静态零偏。确定常数的平移不改变姿态及 P。
- EKF 角速度反馈采用 `raw + static_offset - residual_bias`（X/Y）；Z 使用静态补偿。状态转换保持 X/Y 当前校正角速度连续，不意味着转换瞬间残余零偏为零。Z 在校准结束时开始扣除静态偏置，不保证这一刻的角速度连续。
- 首次 dt 为任务标称 2 ms，后续使用无符号微秒差值，支持正常回绕。重复时间戳和超过 10 ms 的间隔跳过更新。
- 无效角速度、无效/零模长加速度和异常 dt 不进入 EKF；矩阵求逆失败退回预测状态；后验四元数归一化，反三角函数输入限幅。
- 保留 Q1=10、Q2=0.001、R=8000000、lambda=1，未声称适合所有工况。

## 回退

在 `Application/ConfigLayer/rp_config.h` 设置并重新编译烧录：

```c
#define IMU_USE_MAHONY  1
#define IMU_USE_EKF     0
```

两个宏必须且只能启用一个。切回 Mahony 不会撤销安装角注释修复。

## 验证与局限

主机测试：`python -m unittest discover -s test/imu -p "test_*.py"`，执行从固件提取的 C 代码，覆盖初始重力方向、零偏反馈、回退反馈、时间戳回绕/重复/长间隔，以及无效输入拒绝。校准交接测试覆盖 2000 次累加、完成帧、后续帧、X/Y 状态及缓存一致性、输出连续性、超限丢弃和 Mahony 分支。传感器和数学函数使用主机替身，不覆盖 MCU 调度及 CMSIS 矩阵数值行为。

校准仍需人工保持静止，2000 次约需 4 秒以上。当前超出 0.005 rad/s 的 offset 会被清零；校准期仍允许姿态发送及控制。本次三轴补偿和状态交接不包含静止检测、温稳检测、校准失败重试或控制使能门控，不保证温度在 4 秒内稳定。

上板先核对水平状态变换后加速度是否接近 `(0,0,+9.8)`，再检查单轴角度、角速度及板间通信符号，尤其注意安装角修复可能改变原有控制方向。保持上电采样阶段静止。

跳过异常更新会保留上次姿态，不补算丢失期间的运动；当前通信仍可能发布该姿态。持续数据故障、长期停顿恢复和控制端新鲜度处理需要另行验证。初始无效加速度使用单位四元数兜底，并不表示传感器恢复正常。

六轴 EKF 无绝对 yaw 参考，不保证消除 yaw 漂移。需实际测量执行耗时、堆/栈余量、温漂、振动下误差和控制延迟；本次未上板测试或烧录。
