# 移除自瞄控制设计

## 目标与范围

移除下层板中不再需要的自瞄遥控开关和自瞄状态，不改变现有机械模式、陀螺仪模式、小陀螺模式、云台 pitch、发射机构、超电或键鼠控制行为。

本次涉及 Down 控制层中自瞄枚举、控制标志和拨轮向下的自瞄切换分支；同时清理 Up/Down 中将预留通信字节描述为自瞄用途的注释，以及 Down UI 注释中的自瞄示例。通信报文格式、字段位置和预留字节行为均保持不变。Up 没有自瞄运行逻辑，不修改其控制行为。

## 行为与接口变更

- 保留 S1、S2 和拨轮用于现有底盘模式切换的行为。
- 保留 S1 中位、S2 中位加拨轮向上切换摩擦轮的行为。
- 移除 S1 中位、S2 中位加拨轮向下切换自瞄的行为。
- 从 `CarFlags_t` 移除视觉模式字段，并删除不再使用的 `VisionMode_e` 枚举。
- 初始化和遥控器失联处理继续复位所有现存控制标志，但不再维护视觉模式状态。
- 更新相关函数说明，使其准确描述剩余的摩擦轮与发射行为。
- CAN 状态/指令帧的长度、ID、数据布局保持不变；通用描述继续说明相关字节预留扩展。

## 组件与数据流

Down 的 `Car_Control_Update` 仍检测拨轮边沿并调用模式切换逻辑。动作处理仅接收并处理拨轮向上边沿，用于摩擦轮控制；拨轮向下边沿仍供模式切换逻辑使用，不再传入动作处理函数。单发、连发、摩擦轮和失联保护逻辑保持不变。

Up/Down 的通信层仅调整预留字节注释，不新增、删除或重排任何报文字段。Down UI 仍可显示已有状态文本，但本次不添加或保留自瞄状态展示功能。

## 验证

- 全仓搜索确认不存在 `VISION_AUTO_AIM`、`VISION_OFF`、`vision_mode` 等控制状态引用。
- 检查拨轮向下边沿仍连接到底盘模式切换；拨轮向上摩擦轮切换和单发/连发逻辑未变。
- 检查 Up/Down 通信帧 ID、长度和数据布局无变更。
- 运行现有相关测试；若可用则编译 Down Keil 工程，确认移除结构体字段后无残余引用或编译错误。
