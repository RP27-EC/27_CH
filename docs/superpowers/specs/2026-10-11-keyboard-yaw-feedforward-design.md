# GYRO 键鼠底盘跟随前馈

用户已在前一轮设计说明之后明确要求增加与遥控类似的前馈，本次直接在现有下板工程落实。目标是鼠标驱动云台时让底盘提前跟随，减少必须先形成夹角才能追赶的滞后。

采用等效摇杆方案：鼠标角增量 `-mouse_x * MOUSE_YAW_SENS` 除以实际有效 DBUS 帧间隔，得到 rad/s，再乘 `0.002 / gyro_sensitivity` 并取反，转成与 ch0 同符号的等效通道。键鼠倍率默认 1，等效通道限制在 ±660。GYRO 键鼠的 rotate 通道承载这个前馈量，复用底盘现有死区、0.20 低通、0.8 前馈增益及夹角反馈；保留 Chassis_Update 接口、遥控路径、瞄准灵敏度和 PID 参数。

相比直接增大夹角反馈，此方案能在误差变大前响应；相比单独复制底盘前馈控制器，此方案复用已存在的遥控链路，减少两套逻辑分歧。归一化参考取满杆云台期望转速，初始手感与遥控前馈相近，不宣称是已标定的底盘物理转速模型。

DBUS 接收记录最近有效帧的 HAL 毫秒时间、相邻有效帧间隔和接收标记。首次、同毫秒或超过 50 ms 的间隔不计算速度。鼠标位移仍每个新序号只累加一次；前馈速度在两个 DBUS 帧之间保持，不在每个 2 ms 周期重复累加位移。序号和时间允许无符号回绕。

只在 GYRO、键鼠、有效遥控、云台工作及上板在线、Ctrl 未按住时输出鼠标前馈。模式/输入源切入时丢弃旧前馈，等待新帧；退出、小陀螺、失联、Ctrl 微调、无效时序或数据清零。原始 mouse_vx 为零的新帧立即停止前馈，不保留底盘低通尾值；原有十帧鼠标均值滤波及其角目标尾部不改。最后一帧超过 50 ms 后也停止前馈。底盘停车和输入源/模式切换清零前馈滤波历史。

短临界区取得鼠标序号、数据、时间及 Ctrl 快照，计算在恢复原 PRIMASK 后进行。新的诊断与倍率放在 hero_gimbal.yaw 中，方便 Watch；超电、裁判、功率旁路和现有未提交 PID 调参保持用户当前版本。

验收：真实 C 链路在机械夹角为零时已产生方向正确的轮速；14/28 ms 的等速输入生成相同等效通道；同帧重复控制不重积分；零输入、超时、换源、模式变化与失联停止前馈；过大/非法输入有界；遥控、WASD、Q/E、Ctrl、小陀螺及现有云台控制回归通过。ARMCC5 全量构建，不烧录。实车仍需按夹角与轮速能力调前馈倍率。
